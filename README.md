# Учёт артикулов склада — V3

Краткая структура проекта (упрощённый рефакторинг):

- `index.html` — точка входа (подключает CSS и `js/app.js`).
- `css/styles.css` — все стили вынесены из HTML.
- `js/app.js` — основной JavaScript (перенесён из `artikuly_sklad_v3.html`).
- `artikuly_sklad_v3.html` — оригинал оставлен как резерв.

Как запустить

1. Откройте `index.html` в браузере (или запустите простой static-server).

Примечания и рекомендации

- Для дальнейшей модульной разбивки можно разделить `js/app.js` на несколько модулей: `utils`, `storage`, `ui`, `importExport`, `bom`.
- Рассмотрите добавление `package.json` и bundler (Vite/webpack) для управления зависимостями и офлайн-версий библиотек.
